# Security policy

## Reporting a vulnerability

Please report security issues privately to `contact@ali-hasanov.com`. Do not open a public issue for credential exposure, arbitrary code execution, or unintended transcript and project-context disclosure.

Include the affected version, reproduction steps, impact, and any suggested mitigation. Acknowledgement is targeted within seven days.

## Sensitive data

- Never commit API keys, recordings, transcripts, or private project context.
- Use only recordings that you own or have permission to process.
- Review the configured AI provider's retention and privacy terms before sending sensitive content.
- Treat generated text as untrusted until reviewed.

Only the latest release is supported with security fixes.
